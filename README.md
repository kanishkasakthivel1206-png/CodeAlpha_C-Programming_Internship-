# CodeAlpha C Programming Internship

This repository contains C programming projects completed as part of my CodeAlpha Internship.

## Projects

### Task 1 - Basic Calculator
A C program that performs basic arithmetic operations using switch case.

### Task 2 - Matrix Operations
A C program implementing matrix addition, multiplication, and transpose using functions and 2D arrays.

### Task 3 - Student Management System
A menu-driven C program for adding, deleting, updating, searching, and displaying student records using structures and file handling.

### Task 4 - Banking System
A mini bank account management system implementing deposit, withdrawal, and balance enquiry.
